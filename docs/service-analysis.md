# 서비스 분석

## 분석 목적

무신사 웹에서 상품을 검색하고, 상품 상세 페이지에서 옵션을 선택한 뒤 장바구니 또는 결제 진입까지 이어지는 사용자 흐름을 파악한다. 이후 이 흐름을 기준으로 기능 분석, 리스크 분석, 테스트 케이스와 자동화 범위를 정한다.

## 분석 범위

- 상품 검색 결과 확인
- 검색 결과에서 상품 상세 페이지 진입
- 상품 옵션 선택
- 장바구니 담기 및 장바구니 확인
- 바로 결제하기 또는 장바구니에서 결제하기 선택
- 비로그인 상태에서 로그인 화면으로 전환되는 지점

실제 주문 완료와 결제 승인은 이번 분석 범위에 포함하지 않는다.

## 확인된 사용자 여정

1. 상품을 검색하면 검색 결과에 상품 목록이 표시된다.
2. 검색 결과에서 상품을 선택하면 상품 상세 페이지가 새 탭으로 열린다.
3. 상품 상세 페이지에서 구매할 상품 옵션을 선택한다.
4. 옵션 선택 후 다음 경로로 진행할 수 있다.
   - **장바구니 담기**: 비로그인 상태에서도 장바구니에 담을 수 있다.
   - **바로 결제하기**: 비로그인 상태에서는 로그인 화면으로 이동한다.
5. 장바구니에 담은 뒤 장바구니에서 **결제하기**를 선택해도 로그인 화면으로 이동한다.

## 관찰 메모

- 위 내용은 2026-10-12 웹 화면에서 비로그인 상태로 직접 확인한 흐름이다.
- 로그인 화면으로 이동하는 동작은 확인했지만, 로그인 후 결제 절차와 주문 완료는 확인하지 않았다.
- 상품 목록, 가격, 옵션과 화면 구성은 시점이나 상품에 따라 달라질 수 있다.
