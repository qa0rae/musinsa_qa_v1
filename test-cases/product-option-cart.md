# 상품 옵션 및 비로그인 장바구니 탐색 테스트

## 테스트 개요

- 대상: 무신사 웹 상품 상세 및 장바구니
- 실행일: 2026-10-12
- 테스트 방식: 수동 탐색 테스트
- 테스트 데이터: 상품 상세 화면의 체크 셔츠, 옵션 `볼드패턴_브릭레드 · 2(L)`
- 기준 한계: 공개된 기획서/요구사항 없이 화면 동작을 관찰했으므로, 아래 결과는 공식 Pass/Fail 판정이 아닌 탐색 테스트 기록이다.

## 시나리오

| ID | 확인 항목 | 수행 및 기대 결과 | 실제 관찰 | 판정 |
|---|---|---|---|---|
| CART-OPT-001 | 옵션 미선택 상태에서 구매하기 | 구매하기를 눌렀을 때 옵션 선택 안내가 표시된다. | 구매 버튼은 활성화되어 있었고, 클릭 시 “옵션을 선택해 주세요.” 팝업이 표시됐다. | 관찰 완료 |
| CART-OPT-002 | 상품 옵션 선택 | 컬러와 사이즈 선택 후 선택 옵션, 수량, 금액이 표시된다. | 옵션 `볼드패턴_브릭레드 · 2(L)`가 수량 1개, 29,900원으로 표시됐다. | 관찰 완료 |
| CART-OPT-003 | 수량 증가 및 합계 계산 | 수량을 2개로 변경하면 합계가 단가 × 수량으로 계산된다. | 29,900원 × 2개 = 59,800원으로 변경됐다. | 계산 확인 |
| CART-OPT-004 | 최소 수량 제한 | 수량 1개에서 감소할 수 없도록 처리된다. | 1개 상태에서 `-` 버튼이 비활성화됐다. | 관찰 완료 |
| CART-OPT-005 | 선택 옵션 삭제 | 옵션의 `×`를 누르면 해당 옵션과 수량·합계가 제거 또는 초기화된다. | 옵션이 사라지고 수량 및 합계가 초기화됐다. 이후 구매하기 클릭 시 옵션 선택 안내가 다시 표시됐다. | 관찰 완료 |
| CART-OPT-006 | 비로그인 장바구니 및 결제 진입 | 비로그인 상태의 장바구니 담기와 결제 진입 동작을 확인한다. | 로그인 없이 장바구니에 상품이 담겼고 금액이 유지됐다. `결제하기` 선택 시 로그인 화면으로 이동했다. | 관찰 완료 |

## 판단 및 미확인 사항

- 수량별 합계 계산은 화면에 표시된 단가와 일치했다.
- 비로그인 장바구니 허용 및 결제 전 로그인 요구가 요구사항과 일치하는지는 기획 기준 확인이 필요하다.
- 로그인 완료 후 장바구니 상품 보존 및 결제 화면 복귀 여부는 확인하지 않았다.
- 요구사항 확인 전에는 기능 결과를 공식 Pass/Fail 또는 결함으로 분류하지 않는다.
